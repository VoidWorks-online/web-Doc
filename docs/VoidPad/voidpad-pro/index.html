VoidPad Pro

17 键蓝牙可编程宏键盘，搭载旋转编码器与 0.91 寸 OLED 显示屏。
蓝牙连接即可在线改键，Wi-Fi 支持 OTA 固件更新，三套按键方案随时切换。

备注

VoidWorks Nano 即将开启预售，敬请关注。

1 硬件配置​

特性说明
按键数量17 个可编程宏按键
旋转编码器1 个，支持旋转 + 短按，可自定义功能
显示屏0.91 寸 OLED，实时显示连接状态与 IP 地址
无线连接蓝牙（设备连接 + 在线改键）+ Wi-Fi（OTA 固件更新）
按键方案最多 3 套按键逻辑，旋钮短按切换

2 快速上手​

2.1 开机与关机​

左上角凸起拨杆为电源开关：

  • 拨向左侧 → 开机
  • 拨向右侧 → 关机

2.2 连接蓝牙​

开机后键盘自动进入蓝牙广播模式，无需额外操作。

  1. 打开电脑或手机的蓝牙设置。
  2. 搜索设备 VoidWorks Nano，点击连接。
  3. 屏幕上蓝牙图标由闪烁变为常亮，即连接成功。

2.3 屏幕状态说明​

图标状态含义
蓝牙闪烁配对中正在等待设备连接
蓝牙常亮已连接蓝牙连接成功
无 Wi-Fi 图标未配置尚未设置 Wi-Fi
Wi-Fi 闪烁连接中已配置但未连上（可能是信号差或密码错误）
Wi-Fi 常亮 + IP 地址已连接Wi-Fi 连接成功，左上角显示键盘 IP

2.4 旋钮功能​

屏幕右侧旋钮支持自定义功能，默认为音量控制。短按旋钮可在不同控制模式间切换，最多支持 3 套按键逻辑。

3 Wi-Fi 配置​

Wi-Fi 用于 OTA 固件更新，非必须步骤——蓝牙连接即可正常使用键盘和在线改键。Wi-Fi 通过配置工具进行设置。

3.1 打开配置工具​

  1. 确认键盘已通过蓝牙连接到电脑。
  2. 打开 VoidWorks 键盘在线配置工具，连接键盘。

3.2 设置 Wi-Fi​

在配置工具中找到 Wi-Fi 设置选项，选择你的 Wi-Fi 网络名称并输入密码，点击保存并连接。

3.3 确认连接​

键盘会自动重启。重启后 Wi-Fi 图标开始闪烁，连接成功后图标变为常亮，屏幕左上角显示键盘的 IP 地址。

Wi-Fi 图标长时间闪烁？

说明连接失败，可能是信号不佳或密码输入错误。请在配置工具中重新设置 Wi-Fi，或参考下方 常见问题。

4 按键映射配置​

通过 VoidWorks 键盘在线配置工具 可自定义每个按键的功能。配置工具运行在浏览器中，通过蓝牙与键盘通信，无需连接 Wi-Fi。

前提条件

键盘已通过蓝牙连接到电脑，并在浏览器中打开配置工具页面。

4.1 连接键盘​

  1. 确认键盘已通过蓝牙连接到电脑。
  2. 打开 VoidWorks 键盘在线配置工具。
  3. 在页面中点击连接，浏览器会通过蓝牙与键盘配对。

连接成功后，界面右上角将显示键盘型号。

4.2 编辑按键映射​

  1. 点击键盘布局图中的任意按键，右侧会出现对应的配置面板。
  2. 点击下方虚拟键盘中的字母 / 功能键，即可将其映射到选中的按键。
  3. 点击上方已选择的按键可删除该映射。

4.3 保存配置​

编辑完成后，点击页面底部的保存所有配置按钮。弹出"保存成功"提示即表示配置已生效。

5 常见问题​

蓝牙搜索不到 VoidWorks Nano
  1. 确认键盘已开机（电源拨杆拨向左侧），屏幕亮起。
  2. 确认蓝牙图标正在闪烁（广播中）。如果图标常亮，说明已连接到其他设备——先在已配对设备中断开连接。
  3. 尝试关机后重新开机，重置蓝牙广播。
Wi-Fi 图标一直闪烁，无法连接

可能是 Wi-Fi 密码错误或信号太弱：

  1. 通过蓝牙连接键盘，打开 VoidWorks 键盘在线配置工具。
  2. 在配置工具的 Wi-Fi 设置中重新选择网络并输入正确密码。
  3. 保存后键盘会自动重启，等待 Wi-Fi 图标变为常亮。
配置工具无法连接键盘
  1. 确认键盘已开机且蓝牙图标常亮（已连接）。
  2. 确认浏览器支持 Web Bluetooth（推荐使用 Chrome / Edge）。
  3. 检查系统蓝牙是否已开启，浏览器是否有蓝牙权限。
  4. 尝试刷新页面后重新连接。
按键映射保存后没有生效
  1. 确认点击了保存所有配置按钮，并看到"保存成功"提示。
  2. 尝试断开蓝牙后重新连接，让键盘重新加载配置。
  3. 如果问题持续，尝试关机重启键盘。

6 固件更新​

OTA 在线更新（推荐）​

键盘连接 Wi-Fi 后，可通过 VoidWorks 键盘在线配置工具 进行固件更新：

  • 自动更新：配置工具连接键盘后会自动检测是否有新固件，如有更新会弹出提示，按指引操作即可完成升级。
  • 手动更新：在配置工具中找到固件更新选项，手动触发检查并安装最新固件。
信息

OTA 更新需要键盘已配置并连接 Wi-Fi。如尚未配置，请先参考 第 3 节 Wi-Fi 配置。
