VoidModule 显示 - RGB屏幕 2.25寸条形TFT

1. 简介​

RGB屏幕-2.25寸条形TFT屏幕是一款面向嵌入式系统的人机显示模块，采用 ST7789 驱动方案，分辨率为 76 x 284，通信接口为 SPI。

该模块适合用于设备状态条显示、仪表面板信息显示、轻量图形交互界面等场景。文档以模块实物接入和工程集成为重点，不以芯片手册翻译为目标。

信息

本页同时包含“模块实物参数”和“同规格面板参考参数”。如出现差异，以本模块实物、原理图及实测结果为准。

2. 核心特点​

  1. 屏幕尺寸：2.25 inch（条形）
  2. 驱动方案：ST7789
  3. 显示分辨率：76 x 284
  4. 通信接口：SPI
  5. 模块供电：+3.3 V ~ +5.0 V
  6. 模块排针：2.54 mm，共 8 Pin

4. 引脚定义​

4.1 引脚表（2.54 mm 排针）​

引脚序号引脚名称类型电平属性功能描述
1GND电源地0 V系统地
2VCC电源输入+3.3 V ~ +5.0 V模块电源输入
3SDA输入3.3 V 逻辑SPI 数据输入（MOSI）
4SCL输入3.3 V 逻辑SPI 时钟输入（SCK）
5RST输入3.3 V 逻辑硬件复位（低有效）
6DC输入3.3 V 逻辑数据/命令选择
7CS输入3.3 V 逻辑SPI 片选
8BL输入3.3 V 逻辑背光使能/调光（PWM）

4.2 引脚注意事项​

  1. SDA/SCL 建议走短线并保持良好接地回流。
  2. 主控若为 5 V 逻辑系统，需确认电平兼容，必要时增加电平转换。
  3. BL 引脚用于背光控制，调光建议使用 PWM。
警告

供电与信号地必须共地；未共地时可能出现花屏、无显示或通信异常。

6.1 与 STM32（SPI1）接线示例​

6.2 接线建议​

  1. 初次调试建议从 8 MHz SPI 时钟开始验证，再逐步提升。
  2. 背光与逻辑供电建议保证足够电源裕量，避免压降导致闪屏。
  3. 长线连接时建议降低 SPI 时钟并加强接地。
提示

如果首屏不亮，先固定 BL 为高电平，再排查 SPI 和初始化流程。

7. 通信说明 / 控制方法​

7.1 接口与时序建议​

项目建议值说明
总线类型SPI4 线串行
SPI 模式Mode 0（推荐）异常时可尝试 Mode 3
数据位宽8 bitMSB First
SPI 时钟频率8 ~ 40 MHz（建议）先低速验证稳定性
复位低电平时间>= 10 ms（建议）硬件复位
上电稳定延时>= 120 ms（建议）初始化前等待
像素格式RGB565（推荐）/ RGB666（可选）兼顾带宽与色彩

7.2 常用控制命令（参考）​

命令名称说明
0x01SWRESET软件复位
0x11SLPOUT退出休眠
0x29DISPON开启显示
0x2ACASET列地址窗口设置
0x2BRASET行地址窗口设置
0x2CRAMWR写入像素数据

7.3 控制流程建议​

  1. 上电后等待 >= 120 ms。
  2. RST 拉低 >= 10 ms 后拉高，再等待 >= 120 ms。
  3. 发送初始化命令（像素格式、方向、窗口等）。
  4. 执行清屏并开启背光。
  5. 按区域刷新或整屏刷新。

8. 快速上手​

8.1 你需要准备​

  1. RGB屏幕-2.25寸条形TFT屏幕模块
  2. STM32 开发板（或其他 3.3 V SPI 主控）
  3. 连接线与稳定电源

8.2 最小验证步骤​

  1. 按“接线说明”完成硬件连接。
  2. 完成 ST7789 初始化并发送纯色填充。
  3. 依次显示红、绿、蓝、黑、白，确认刷新正常。
  4. 若异常，优先检查 BL 电平、SPI 模式、复位时序。

9. 注意事项​

  1. 模块供电必须在 +3.3 V ~ +5.0 V 范围内，禁止反接。
  2. 通电状态不建议频繁热插拔排线或接口。
  3. 不同批次驱动或玻璃参数可能有差异，初始化参数应按实测调整。
  4. 高亮度长时间运行需评估系统温升与背光寿命。

10. 常见问题​

Q1：屏幕不亮，如何排查？​

  1. 检查 VCC/GND 是否正确且共地。
  2. 检查 BL 是否有效使能。
  3. 检查 RST 时序是否满足建议值。
  4. 检查是否正确发送 0x11 与 0x29。

Q2：显示花屏或错位，如何处理？​

  1. 核对分辨率配置是否为 76 x 284。
  2. 检查窗口命令（0x2A/0x2B）与方向配置。
  3. 降低 SPI 时钟后复测稳定性。
  4. 检查排线接触和地线完整性。

Q3：刷新慢或撕裂，如何优化？​

  1. 使用 DMA 或批量缓存发送像素数据。
  2. 优先使用局部刷新而非全屏重绘。
  3. 在稳定前提下提高 SPI 时钟。
  4. 优化 UI 刷新策略，减少无效重绘。
