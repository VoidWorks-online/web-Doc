快速上手​

开机​

左上角凸起拨杆为电源开关。

  • 拨向 左侧 为开机
  • 拨向 右侧 为关机

屏幕显示说明​

  • 蓝牙配对中：蓝牙图标闪烁
  • 蓝牙连接成功：蓝牙图标常亮

关于 Wi-Fi 图标状态：

  • 未配置 Wi-Fi 时：不显示图标
  • 已配置但未连接时：Wi-Fi 图标闪烁（长时间闪烁可能是信号不佳或密码错误，请参考“清除密码”部分）
  • 成功连接 Wi-Fi 后：Wi-Fi 图标常亮，屏幕左上角显示键盘 IP 地址

旋钮功能​

屏幕右侧旋钮支持自定义功能。
默认模式为 音量控制。
短按旋钮可在不同控制模式间切换。
Nano 最多支持 三套按键逻辑 切换。

蓝牙连接​

开启 VoidWorks Nano 后，设备将自动进入蓝牙广播模式。
在电脑的蓝牙设置中搜索 VoidWorks Nano，点击连接即可。

连接 Wi-Fi​

  1. 在电脑或手机中连接键盘的 Wi-Fi 网络 Nano-Config。
  2. 稍等片刻，浏览器会自动弹出如下配置页面：

如果未自动弹出，请在浏览器中访问 http://192.168.4.1。

  1. 从下拉菜单中选择 Wi-Fi 名称并输入密码，点击 保存并连接。
  2. 键盘将自动重启。
  3. 重启后 Wi-Fi 图标闪烁，连接成功后屏幕将显示键盘的 IP 地址。

键盘按键映射配置器​

打开 VoidWorks 键盘控制器。

连接键盘​

在页面中间的输入框中，输入键盘屏幕上显示的 IP 地址。

⚠️ 注意：电脑与键盘必须连接到同一 Wi-Fi 网络。

连接成功后，界面右上角将显示键盘型号。
点击任意按键，右侧将出现对应的配置选项卡。

点击下方键盘字母可选择映射按键，点击上方已选择按键可删除操作。
设置完成后，点击页面底部的 保存所有配置 按钮。
弹出提示“保存成功”后，即表示配置已生效。
