VoidCore G4 – STM32G431CBU6

基于 STM32G431CBU6 的开发板

一块基于 STM32G431CBU6（Cortex-M4，170 MHz）的自制进阶学习开发板。
面向高频 PWM、快速 ADC 采样、实时控制算法和高性能模拟外设应用，并引出 SWCLK / SWDIO / RST / 3V3 / GND 五线 SWD 调试接口。
适合用于电机控制、数字电源、控制回路验证和高性能外设练习。

1 特性一览​

特性说明
核心芯片STM32G431CBU6（Arm Cortex-M4，170 MHz）
Flash / RAM128 KB / 32 KB（22 KB SRAM + 10 KB CCM SRAM）
封装UFQFPN-48（7 × 7 mm）
供电方式板级供电方式以原理图为准，MCU 典型工作电压为 3.3 V
调试接口五线 SWD（SWCLK、SWDIO、RST、3V3、GND，支持 ST-Link / DAP-Link / J-Link）
板载串口以硬件版本和原理图为准
可用 GPIO最多 41 个（含复用功能）
通信外设3× I2C、3× SPI（其中 2 组支持 I2S 复用）、4× USART/UART、1× LPUART、1× FDCAN、1× USB FS、1× SAI
模拟外设2× 12-bit ADC（最高 4 Msps）、4× 12-bit DAC 通道、3× OPAMP、4× COMP
定时器1× 32-bit 定时器、多组 16-bit 高级/通用定时器、2× 基本定时器、1× 低功耗定时器
特色CORDIC + FMAC 数学加速器，模拟外设丰富，适合控制类与算法类应用
这块板适合做什么
  • 想做高频 PWM 与闭环控制：电机、数字电源、控制回路验证
  • 想做高采样率 ADC 实验：电流/电压采样、滤波与估算
  • 想用 Cortex-M4F 跑实时算法：控制器、观测器、快速数学运算
  • 想从基础 STM32 板进阶到控制类应用：外设更强、调参空间更大

2.2 引脚定义​

关于引脚编号

STM32G431CBU6 采用 UFQFPN-48 封装，共 48 个引脚，并带有 1 个底部散热焊盘。
以下表格列出该封装开发调试中最常用的信号与主要复用功能，便于开发时查阅。完整引脚复用请以官方 Datasheet 为准。

UFQFPN-48 常用引脚表（节选）​

引脚/信号类型主要复用功能（常用）
VDD / VSSS数字电源 / 地
VDDA / VSSAS模拟电源 / 模拟地
NRSTI/O复位（低电平有效）

S = 电源引脚，I/O = 通用输入/输出。复用功能仅列出最常用项，完整映射请参考 ST 官方 Datasheet。

4 快速上手​

你需要准备
  • USB 数据线 × 1（注意要数据线，不要只能充电的线）
  • SWD 调试器 × 1（ST-Link V2 / DAP-Link / J-Link 任选其一）
  • 杜邦线 若干（连接调试器与开发板）
  • 电脑（Windows / macOS / Linux）

4.1 安装开发环境​

  • STM32CubeIDE（推荐）
  • Keil MDK
  1. 前往 ST 官网 下载 STM32CubeIDE。
  2. 安装完成后首次启动，选择一个 Workspace 文件夹。
  3. 菜单 File → New → STM32 Project，在芯片选择器中搜索 STM32G431CBUx。
  4. 填写项目名称，Targeted Language 选 C，选择对应固件包后完成创建。
  5. 如 ST-Link 未被系统识别，可补装 STSW-LINK009。
  1. 下载并安装 Keil MDK。
  2. 打开 Pack Installer，搜索 STM32G4，安装对应 Device Family Pack。
  3. 新建项目时 Device 选择 STM32G431CBUx。
  4. 安装 ST-Link 驱动后即可下载调试。

4.2 接线​

本开发板引出了 SWCLK / SWDIO / RST / 3V3 / GND 五线 SWD 调试接口，推荐按下表连接：

调试器 (ST-Link)          开发板 SWD 接口
─────────────            ──────────────
3V3   ────────────────── 3V3
GND   ────────────────── GND
SWDIO ────────────────── SWDIO (PA13)
SWCLK ────────────────── SWCLK (PA14)
NRST  ────────────────── RST   (NRST)
注意事项
  1. 调试器输出电压请与开发板逻辑电压匹配。
  2. 烧录时请确认开发板已经稳定上电。
  3. 如果连接了 RST，调试器可以自动复位芯片，调试稳定性通常更好。
  4. 开发早期不要轻易复用 PA13 / PA14，否则可能出现无法连接芯片的问题。
  5. 如果下载失败，可在 IDE 中尝试降低 SWD 频率，或使用 Connect Under Reset。

4.3 烧录验证​

  1. 用 USB 数据线连接开发板到电脑并确认上电。
  2. 用杜邦线将 SWD 调试器与开发板的 SWCLK / SWDIO / RST / GND / 3V3 连接好。
  3. 在 STM32CubeIDE 或 Keil 中创建一个简单的 GPIO 点灯工程并编译下载。
  4. 如果程序能正常烧录并运行，即表示开发环境与调试连接正常。

如果硬件版本引出了串口功能，也可以配合串口工具进一步验证日志输出是否正常。

5 常见问题​

烧录时提示 "No target connected" 或 "Error connecting to target"
  1. 检查 SWD 线和供电是否连接正常，尤其是 GND / SWDIO / SWCLK / RST。
  2. 确认调试器驱动已安装。
  3. 确认开发板已经正常上电，3.3 V 电压正常。
  4. 在 IDE 中尝试降低 SWD 频率或使用 Connect Under Reset。
  5. 如果之前误把 PA13 / PA14 配成普通 GPIO，可尝试在复位状态下重新连接并擦除程序。
下载成功但程序运行异常怎么办？
  1. 确认时钟树配置与目标频率一致。
  2. 检查启动文件和链接脚本是否对应 STM32G431CBUx。
  3. 检查外设引脚复用是否与实际硬件连接一致。
  4. 如涉及高级定时器、ADC 或模拟外设，建议先从最小工程开始逐项验证。
ADC 读数不准或一直为 0
  1. 建议先执行 ADC 自校准。
  2. 确认引脚被配置为模拟输入模式，没有使能上下拉。
  3. 用万用表确认输入电压真实存在。
  4. 如涉及模拟量采样，建议检查采样时间与采样源阻抗是否匹配。
如何判断 USB 线是数据线还是充电线？

插上电脑后如果开发板上电了，但系统没有识别出任何新设备，通常说明这根线可能只支持充电。换一根数据线再试。
