VoidCore G4 – STM32G431CBU6

基于 STM32G431CBU6 的进阶开发板

一块基于 STM32G431CBU6（Cortex-M4，170 MHz）的进阶开发板。
面向 高频 PWM、快速 ADC 采样、控制算法验证 和 高性能模拟外设实验，并引出 五线 SWD 调试接口。
适合用于电机控制、数字电源、控制回路与高性能通用外设练习。

1 特性一览​

特性说明
核心芯片STM32G431CBU6（Arm Cortex-M4，170 MHz）
Flash / RAM128 KB / 32 KB（含 CCM SRAM）
封装UFQFPN-48
供电方式板级供电方式以原理图为准，MCU 典型工作电压为 3.3 V
调试接口五线调试接口（+5V、GND、RST、SWCLK、SWDIO）
板载串口无 USB 串口引出
可用 GPIO最多 41 个（按封装与复用情况分配）
通信外设3× I2C、3× SPI、4× USART / UART、1× LPUART、1× FDCAN、1× USB FS、1× SAI
模拟外设2× 12-bit ADC、DAC、OPAMP、COMP
定时器多组高级 / 通用定时器、32-bit 定时器、低功耗定时器
特色CORDIC、FMAC、丰富模拟外设、3.3V 电源指示灯、原生 USB，适合控制类与算法类应用
这块板适合做什么
  • 高频 PWM 与闭环控制实验
  • 高采样率 ADC 与信号调理实验
  • 电机控制、数字电源与控制回路验证
  • 从基础 STM32 过渡到控制类应用平台
不建议用于
  • 只做最基础点灯和简单串口练习的入门场景
  • 还未熟悉基础时钟树和定时器的初学者直接上手复杂控制工程
  • 缺乏外部功率级与模拟前端的高功率实验

2.2 引脚定义​

关于引脚编号

STM32G431CBU6 采用 UFQFPN-48 封装。
该系列重点在于控制类定时器、快速 ADC 和丰富的模拟外设。
完整引脚复用请以 ST 官方数据手册为准。

信号说明
PA13SWDIO，调试专用
PA14SWCLK，调试专用
NRST复位信号
USB D- / D+原生 USB 相关引脚，具体请以数据手册为准
ADC / PWM / OPAMP / COMP 相关引脚以具体工程分配为准

4 快速上手​

你需要准备
  • USB 数据线或板卡供电方案 × 1
  • SWD 调试器 × 1
  • 杜邦线 若干
  • 电脑（Windows / macOS / Linux）

4.1 安装开发环境​

  • STM32CubeIDE（推荐）
  • Keil MDK
  • VS Code / CMake
  1. 安装 STM32CubeIDE。
  2. 创建项目时搜索 STM32G431CBU6。
  3. 选择 C 工程并安装 G4 系列固件包。
  1. 安装 Keil MDK。
  2. 安装 STM32G4xx DFP。
  3. 创建设备项目时选择 STM32G431CBUx。
  1. 安装 VS Code 或使用现有 CMake / CLion 环境。
  2. 配置 ARM GCC、OpenOCD 与 ST-Link。
  3. 导入或创建最小工程后开始验证。

4.2 接线​

调试器                    开发板调试接口
─────────────            ──────────────
+5V          ─────────── +5V
GND          ─────────── GND
RST          ─────────── NRST
SWCLK        ─────────── PA14
SWDIO        ─────────── PA13
注意事项
  1. 在开始控制类实验前，先用最小点灯工程验证基本下载链路。
  2. 若涉及 PWM 驱动功率级，请先确认保护链路和电源隔离。
  3. 不要在未确认板级连线前直接加载复杂控制工程。

4.3 烧录验证​

  1. 确认开发板供电正常。
  2. 连接 SWD 调试器。
  3. 下载最小点灯或串口日志工程。
  4. 验证通过后再逐步引入 ADC、PWM 和控制算法。

7 常见问题​

Q1：为什么这块板更适合进阶而不是纯入门？

因为它的优势主要在于高级定时器、快速 ADC 和模拟外设，真正发挥价值通常需要更系统的时钟、采样和控制知识。

Q2：做电机或电源控制前应该先验证什么？

先验证供电、SWD 下载、GPIO、PWM、ADC 单独功能，再做采样同步和闭环控制。

Q3：没有板载资源明确说明时该怎么开发？

先以原理图和实际硬件版本为准，把板级连线确认清楚后再固化到工程和文档里。
