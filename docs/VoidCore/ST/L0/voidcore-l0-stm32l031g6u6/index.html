VoidCore L0 – STM32L031G6U6

基于 STM32L031G6U6 的开发板

一块基于 STM32L031G6U6（Cortex-M0+, 32 MHz）的超低功耗自制学习开发板。
USB Type-C 接口供电，板载五线 SWD 调试排针，BOOT0 拨码开关，插上线就能烧录。
超低功耗是本板最大亮点 — Standby 仅 0.23 µA，Stop + RTC 仅 0.6 µA，适合电池供电与低功耗场景学习。

超低功耗亮点

STM32L031G6U6 属于 ST 的 L0 超低功耗系列，在同级 MCU 中功耗表现优异：

  • Standby 模式：仅 0.23 µA（2 个唤醒引脚）
  • Stop 模式：0.35 µA（16 个唤醒线）
  • Stop + RTC + 8 KB RAM 保持：0.6 µA
  • Run 模式：低至 76 µA/MHz
  • 唤醒时间：5 µs（从 Flash）
  • 工作电压：1.65 V ~ 3.6 V，可直接使用单节锂电池或两节干电池供电

非常适合学习低功耗设计、电池供电传感器节点、可穿戴原型等场景。

2.2 引脚定义​

关于引脚编号

STM32L031G6U6 采用 UFQFPN-28 封装，共 28 个引脚（含 1 个底部散热焊盘 Pad 29）。
其中 31 个 I/O 口中有部分为 5 V 容忍引脚。本开发板将大部分 GPIO 引出至面包板排针。

BOOT0 拨码开关注意
  • 正常使用时 BOOT0 应拨到 0 位置（从 Flash 启动）。
  • 拨到 1 后芯片进入系统存储器 Bootloader 模式（USART/SPI ISP 烧录），此时 SWD 调试也可正常使用。
  • 如果芯片被锁死（PA13/PA14 被误配为 GPIO），可将 BOOT0 拨至 1 并复位，即可恢复 SWD 连接后重新擦除。

4 快速上手​

你需要准备
  • USB Type-C 数据线 × 1（注意要数据线，不要只能充电的线）
  • SWD 调试器 × 1（ST-Link V2 / DAP-Link / J-Link 任选其一）
  • 杜邦线 若干（连接调试器与开发板）
  • 电脑（Windows / macOS / Linux）

4.1 安装开发环境​

  • STM32CubeIDE（推荐）
  • Keil MDK
  • PlatformIO + VS Code
  1. 前往 ST 官网 下载 STM32CubeIDE（免费，全平台支持）。
  2. 安装完成后首次启动，选择一个 Workspace 文件夹。
  3. 菜单 File → New → STM32 Project，在芯片选择器中搜索 STM32L031G6U6，选中后点击 Next。
  4. 填写项目名称，Targeted Language 选 C，Firmware Package 选最新版本，完成创建。
  5. ST-Link 驱动通常随 CubeIDE 自动安装。如果设备管理器识别不到，可手动安装 STSW-LINK009。
  1. 下载并安装 Keil MDK（Community 版免费，限制 32 KB 代码——刚好覆盖本芯片 Flash 容量）。
  2. 打开 Pack Installer，搜索 STM32L0，安装 Keil.STM32L0xx_DFP 包。
  3. 新建项目时 Device 选择 STM32L031G6Ux。
  4. 安装 ST-Link 驱动：STSW-LINK009。
  1. 安装 VS Code，在扩展商店搜索 PlatformIO IDE 并安装。
  2. 新建项目，Board 选择 genericSTM32L031G6，Framework 选 stm32cube。
  3. PlatformIO 会自动下载对应的 HAL 库和工具链。

4.2 接线​

本开发板配备五线 SWD 排针，接线如下：

调试器 (ST-Link)          开发板 SWD 排针
─────────────            ──────────────
+5V   ────────────────── +5V  （可选，板子 Type-C 自带供电）
GND   ────────────────── GND
SWDIO ────────────────── DIO  (PA13)
SWCLK ────────────────── CLK  (PA14)
NRST  ────────────────── RST  （可选，支持调试器硬件复位）
注意事项
  1. 调试器输出电压可以使用 3.3 V 或者 5 V。
  2. 烧录时建议同时用 Type-C 数据线供电，调试器的电源仅作为信号参考，不建议单独作为板子电源。
  3. 如果连接了 RST，调试器可以自动复位芯片；未连接时在 IDE 中选择 Software Reset 即可。
  4. 禁止 ST-Link 在 +3.3 V 供电的同时接入 Type-C，可能会烧毁 ST-Link。
  5. 如果 SWD 连不上，先检查 BOOT0 拨码开关是否在 0 位置。

4.3 烧录验证​

  1. 用 Type-C 数据线连接开发板到电脑（板子上电指示灯亮起）。
  2. 用杜邦线按照上面的接线图连接 SWD 调试器。
  3. 打开 STM32CubeIDE / Keil，创建一个简单的 GPIO 点灯工程，编译烧录。
  4. 看到 LED 闪烁即表示环境搭建成功。

5 低功耗模式速查​

STM32L031G6U6 的低功耗能力是本开发板的核心卖点。以下是各低功耗模式的典型功耗参考：

模式典型电流唤醒源唤醒时间说明
Run（32 MHz）~2.4 mA——全速运行，代码从 Flash 执行
Run（低功耗，32 kHz MSI）~2.4 µA——低频运行，极低功耗
Low-power Run~8 µA——低功耗调压器 + MSI 时钟
Sleep~1 mA任意中断1 µsCPU 停止，外设运行
Low-power Sleep~4.5 µA任意中断—低功耗调压器 + CPU 停止
Stop + RTC~0.6 µARTC / EXTI / LPUART / I²C / USART / COMP / LPTIM5 µsRAM 保持，最常用低功耗模式
Stop（无 RTC）~0.35 µAEXTI / LPUART / I²C / USART / COMP / LPTIM5 µsRAM 保持
Standby~0.23 µAWKUP 引脚 / RTC—RAM 不保持，仅备份寄存器保留
低功耗设计建议
  1. 优先使用 Stop 模式 — 它在极低功耗的同时保持 RAM 内容和 RTC 运行，唤醒后可快速恢复。
  2. 善用 LPUART / LPTIM — 这两个外设可在 Stop 模式下继续工作并唤醒 MCU，非常适合低功耗通信和定时任务。
  3. 板载 32.768 kHz LSE 晶振 — 本板已焊接 32.768 kHz 晶振，可直接为 RTC、LPTIM、LPUART 提供精准时钟，无需依赖精度较差的 LSI（±5%），Stop 模式下 RTC 计时精度大幅提升。
  4. MSI 时钟 — 多速率内部 RC（65 kHz ~ 4.2 MHz），无需外部晶振即可灵活调频以降低功耗。
  5. 1 KB 数据 EEPROM — 可直接按字节读写，无需像 Flash 一样整页擦除，适合存储校准参数和低功耗传感器数据。
  6. 测量实际功耗时，记得断开 SWD 调试器和 USB，使用电池直接给 VDD 供电并串联万用表电流挡。

6 常见问题​

烧录时提示 "No target connected" 或 "Error connecting to target"
  1. 检查 SWD 线（尤其 GND）是否接牢。
  2. 确认调试器驱动已安装——在设备管理器中应能看到 ST-Link 设备。
  3. 确认 Type-C 已插入且板子有供电（用万用表量 3.3 V 是否正常）。
  4. 在 IDE 的调试器设置中尝试降低 SWD 频率（如从 4 MHz 降到 480 kHz）。
  5. 如果芯片之前被错误配置了 PA13/PA14 为 GPIO，将 BOOT0 拨码拨至 1，复位后即可恢复 SWD 连接，重新擦除芯片。
功耗测量值比 Datasheet 高很多
  1. 确认已断开 USB Type-C 和 SWD 调试器——它们的漏电流远大于 MCU 本身。
  2. 检查是否有 GPIO 处于浮空输入状态——未使用的引脚应配置为模拟输入或推挽输出低电平以减少漏电。
  3. 确认所有不需要的外设时钟已关闭。
  4. 使用内部低功耗调压器模式（Low-power Regulator），而非主调压器。
  5. VDD 电压越低，功耗越低——如果场景允许，可考虑 1.8 V 供电。
芯片只有 32 KB Flash，代码放不下怎么办？
  1. 编译时开启 -Os（优化代码大小），Keil 中选择 Level 2 + Link-Time Optimization。
  2. 减少 HAL 库中未使用的模块——在 CubeMX 中只勾选实际需要的外设。
  3. 使用 LL 库（Low-Layer）替代 HAL 库，可显著减小代码体积。
  4. 浮点运算改用定点数实现——Cortex-M0+ 无 FPU，软浮点库体积很大。
ADC 读数不准或一直为 0
  1. 建议在 ADC 使用前执行自校准（HAL_ADCEx_Calibration_Start()）。
  2. 确认引脚配置为模拟输入模式，没有使能内部上拉/下拉。
  3. 用万用表测量引脚实际电压，确认硬件连接正常。
  4. STM32L031 的 ADC 可工作在低至 1.65 V 的电压下，但需确认 VDDA 供电正常。
如何判断 Type-C 线是数据线还是充电线？

插上电脑后如果设备管理器中没有出现任何新设备，而板子有供电，说明可能是只能充电的线。换一根线试试——通常两头都有 USB 标志的更可能是数据线。

LPTIM / LPUART 在 Stop 模式下不工作
  1. 确认时钟源选择了 **LSE（推荐，板载已焊 32.768 kHz 晶振）**或 LSI——Stop 模式下 HSI16 和 HSE 均已关闭。
  2. 检查 EXTI 唤醒线是否正确配置。
  3. 在进入 Stop 模式前，确认 LPUART / LPTIM 已使能并配置好中断。
