VoidCore F0 – STM32F070F6P6

基于 STM32F070F6P6 的入门开发板

一块基于 STM32F070F6P6（Cortex-M0，48 MHz）的自制入门开发板。
采用 USB Type-C 供电，板载 CH340 USB 转串口，并引出 +5V / GND / NRST / SWCLK / SWDIO 五线调试接口。
芯片本身带有 原生 USB Full-Speed 外设，适合做基础外设学习与 USB 功能验证。

1 特性一览​

特性说明
核心芯片STM32F070F6P6（Arm Cortex-M0，48 MHz）
Flash / RAM32 KB / 6 KB
封装TSSOP-20
供电方式USB Type-C 5 V 输入，板载 3.3 V LDO
调试接口五线调试接口（+5V、GND、RST、SWCLK、SWDIO）
板载串口CH340 USB 转 UART
可用 GPIO最多 15 个（含复用功能）
通信外设2× USART、1× I2C、1× SPI、1× USB 2.0 FS
模拟外设12-bit ADC
定时器TIM1、TIM3、TIM14、TIM16、TIM17、TIM6、TIM7
特色小封装、原生 USB、白色电源指示灯、五线调试接口，适合低成本 USB 入门实验
这块板适合做什么
  • GPIO / PWM / ADC / UART 基础实验
  • 原生 USB CDC / HID 入门
  • 小尺寸 STM32 板卡原型验证
  • 与 G0 系列做能力差异对比学习
不建议用于
  • 需要更多 GPIO 或更大 RAM 的项目
  • 需要板载丰富人机交互资源的演示板场景
  • 对供电、ESD、防护有较高要求的直接量产应用

2.2 引脚定义​

关于引脚编号

STM32F070F6P6 采用 TSSOP-20 封装，共 20 个引脚。
部分物理引脚存在功能复用冲突，例如串口与原生 USB 在某些场景下需要根据配置进行选择。
完整复用功能请以 ST 官方数据手册为准。

2.3 板载资源映射​

资源连接引脚备注
CH340 TXPA9 / PA11 复用引脚默认用于板载串口通信，具体复用以工程配置为准
CH340 RXPA10 / PA12 复用引脚默认用于板载串口通信，具体复用以工程配置为准
白色电源指示灯3.3 V 电源轨上电常亮，用于电源状态指示
+5VUSB 输入调试接口电压参考
GND—调试与系统共地
NRSTNRST五线调试接口复位信号
SWCLKPA14五线调试接口时钟
SWDIOPA13五线调试接口数据
USB D- / D+PA11 / PA12（复用场景）原生 USB 相关引脚，和串口复用场景需结合工程配置确认
BOOT0 按键BOOT0板载启动模式按键
RST 按键NRST板载复位按键
USB Type-C 5 V 输入—板载供电输入
调试与复用注意事项
  • 板载 CH340 与芯片原生 USB 存在引脚复用关系，请按工程目标选择。
  • 如需启用原生 USB，请核对 PA11 / PA12 与串口复用配置。
  • PA13 / PA14 建议在开发早期始终保留给 SWD。

4 快速上手​

你需要准备
  • USB Type-C 数据线 × 1
  • SWD 调试器 × 1
  • 杜邦线 若干
  • 电脑（Windows / macOS / Linux）

4.1 安装开发环境​

  • STM32CubeIDE（推荐）
  • Keil MDK
  • VS Code / PlatformIO
  1. 下载并安装 STM32CubeIDE。
  2. 新建项目时搜索 STM32F070F6P6。
  3. 选择 C 工程并启用 STM32Cube 固件包。
  4. 检查 ST-Link 驱动是否已正确安装。
  1. 安装 Keil MDK。
  2. 打开 Pack Installer，安装 STM32F0xx DFP。
  3. 创建设备项目时选择 STM32F070F6Px。
  1. 安装 VS Code 与 PlatformIO。
  2. 创建 F070 对应项目。
  3. 配置 OpenOCD 或 ST-Link 调试下载链路。

4.2 接线​

本开发板已引出五线调试接口，可按下表连接：

调试器                    开发板调试接口
─────────────            ──────────────
+5V          ───────────  +5V
GND          ───────────  GND
RST          ───────────  NRST
SWCLK        ───────────  PA14
SWDIO        ───────────  PA13
注意事项
  1. 若需要做原生 USB 实验，先确认程序没有与板载串口资源冲突。
  2. 初次调试建议同时连接 NRST。
  3. 若下载异常，可尝试降低 SWD 频率。

4.3 安装串口驱动​

本板使用 CH340 作为 USB 转串口芯片。

  • Windows
  • macOS
  • Linux

系统通常会自动安装驱动。若未自动识别，可使用 WCH 驱动包。

如未自动识别串口，可安装 CH340 对应驱动后重新插拔设备。

插入后可执行：

dmesg | tail

确认串口设备是否出现。

4.4 烧录验证​

  1. 先确认开发板供电正常。
  2. 连接五线调试接口并下载最小点灯工程。
  3. 验证板载串口输出是否正常。
  4. 如需验证 USB，再单独测试 USB CDC / HID。

7 常见问题​

Q1：为什么串口能用，但原生 USB 工程不工作？

板载 CH340 与芯片原生 USB 并不是同一链路。请检查原生 USB 对应引脚、时钟配置和中间件初始化是否正确。

Q2：下载失败怎么办？
  1. 检查 +5V / GND / NRST / SWCLK / SWDIO 接线是否正确。
  2. 检查供电与地线是否稳定。
  3. 降低 SWD 频率后重试。
  4. 必要时使用空白最小工程排查是否为引脚复用冲突。
Q3：这块板更适合学什么？

建议先完成 GPIO / UART / ADC / PWM，再进入原生 USB CDC 和 HID。
