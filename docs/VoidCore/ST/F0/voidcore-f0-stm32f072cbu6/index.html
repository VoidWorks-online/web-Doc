VoidCore F0 – STM32F072CBU6

基于 STM32F072CBU6 的入门开发板

一块基于 STM32F072CBU6（Cortex-M0，48 MHz）的自制入门开发板。
采用 USB Type-C 供电，引出 SWD 调试接口，兼顾 原生 USB、CAN 与常规外设学习。
在紧凑尺寸下提供更完整的 GPIO 和模拟资源，适合做通用型嵌入式原型板。

1 特性一览​

特性说明
核心芯片STM32F072CBU6（Arm Cortex-M0，48 MHz）
Flash / RAM128 KB / 16 KB
封装UFQFPN-48
供电方式USB Type-C 5 V 输入，板载 3.3 V LDO
调试接口五线调试接口（+5V、GND、RST、SWCLK、SWDIO）
可用 GPIO最多 37 个（按封装与复用情况分配）
通信外设2× I2C、4× USART、2× SPI / I2S、USB 2.0 FS、CAN、HDMI CEC
模拟外设12-bit ADC、2× DAC、2× 比较器
定时器高级定时器、32-bit 通用定时器、多组 16-bit 定时器、RTC
特色原生 USB、CAN、资源均衡，适合扩展型 F0 项目
这块板适合做什么
  • STM32 通用外设学习
  • 原生 USB CDC / HID / DFU 实验
  • CAN 总线入门
  • 需要更多 GPIO 的小型控制和采集项目
不建议用于
  • 需要更高主频和更强算法能力的控制类项目
  • 对模拟精度和采样速率要求更高的电机 / 电源控制场景
  • 需要现成板载交互器件的教学演示板场景

2.2 引脚定义​

关于封装

STM32F072CBU6 采用 UFQFPN-48 封装，并带有 Exposed Pad。
适合在较小板面积中提供较完整的 GPIO、USB、CAN 与 DAC 资源。
完整引脚复用请以 ST 官方数据手册为准。

4 快速上手​

你需要准备
  • USB Type-C 数据线 × 1
  • SWD 调试器 × 1
  • 杜邦线 若干
  • 电脑（Windows / macOS / Linux）

4.1 安装开发环境​

  • STM32CubeIDE（推荐）
  • Keil MDK
  • VS Code / PlatformIO
  1. 安装 STM32CubeIDE。
  2. 新建项目时搜索 STM32F072CBU6。
  3. 选择 C 工程并启用 STM32Cube 固件包。
  4. 确认调试器驱动已就绪。
  1. 安装 Keil MDK。
  2. 安装 STM32F0xx DFP。
  3. 创建设备项目时选择 STM32F072CBUx。
  1. 安装 VS Code 与 PlatformIO。
  2. 建立 F072 对应工程。
  3. 配置下载与调试工具链。

4.2 接线​

调试器                    开发板调试接口
─────────────            ──────────────
+5V          ───────────  +5V
GND          ───────────  GND
RST          ───────────  NRST
SWCLK        ───────────  PA14
SWDIO        ───────────  PA13
注意事项
  1. 若后续需要做 USB 实验，请不要占用 PA11 / PA12。
  2. 若后续需要做 CAN 实验，请先确认是否已准备外置 CAN 收发器。
  3. 初次调试建议用最小 GPIO 点灯工程验证下载链路。

4.3 烧录验证​

  1. 连接开发板到电脑并确认上电。
  2. 连接 SWD 调试器。
  3. 编译下载一个最小点灯工程。
  4. 确认点灯正常后，再开始 USB、CAN 或 DAC 实验。

7 常见问题​

Q1：USB 工程为什么能枚举失败？​

请检查 PA11 / PA12 引脚、USB 时钟配置、电缆质量，以及工程是否启用了正确的 USB 设备类。

Q2：CAN 为什么不能直接通信？​

STM32F072 仅提供 CAN 控制器，实际总线通信还需要外置 CAN 收发器。

Q3：这块板适合从哪些例程开始？​

建议按 GPIO -> UART -> ADC -> USB CDC -> CAN Basic 的顺序逐步验证。
