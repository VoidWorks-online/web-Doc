VoidCore F0 – STM32F072CBU6

基于 STM32F072CBU6 的开发板

一块基于 STM32F072CBU6（Cortex-M0, 48 MHz）的自制学习开发板。
Type-C 接口供电，引出 SWD 调试接口，兼顾原生 USB 实验与常规外设学习。
采用 UFQFPN48 紧凑封装，在保留小尺寸的同时提供较完整的 GPIO、USB FS、CAN、DAC 与多路串口资源。

1 特性一览​

特性说明
核心芯片STM32F072CBU6（Arm Cortex-M0，48 MHz）
Flash / RAM128 KB / 16 KB
封装UFQFPN48（7 × 7 mm，带 Exposed Pad）
供电方式USB Type-C（5 V），板载 3.3 V LDO
调试接口SWD（支持 ST-Link / DAP-Link / J-Link）
可用 GPIO最多 37 个（不含 BOOT0 / 电源脚）
通信外设2× I²C、4× USART、2× SPI/I²S、USB 2.0 FS、CAN、HDMI CEC
模拟外设12-bit ADC（10 个外部通道）、12-bit DAC（2 通道）、2× 比较器
定时器1× 高级定时器、1× 32-bit 通用定时器、5× 16-bit 通用定时器、2× 基本定时器、IWDG、WWDG、SysTick、RTC
这块板适合做什么
  • 想学 STM32 基础外设：GPIO、PWM、ADC、UART、I²C、SPI
  • 想玩 原生 USB：USB CDC / HID / DFU / 自定义 USB 设备
  • 想做 键盘、控制面板、小型仪器：GPIO 资源比小封装 F0 更充裕
  • 想做 总线实验：带 CAN、DAC、比较器，扩展空间更大

2.2 封装与引脚说明​

关于封装

STM32F072CBU6 采用 UFQFPN48 封装，共 48 个外部引脚，并带有 Exposed Pad。
Exposed Pad 建议连接到大面积地铜皮，用于改善焊接强度、散热与 EMC 表现。

关于 GPIO 数量

UFQFPN48 封装下，扣除电源脚、地脚、复位脚与 BOOT0 后，常规可用 GPIO 约为 37 个。
其中 PA11 / PA12 为原生 USB DM / DP，PA13 / PA14 默认用于 SWD 调试，实际分配时建议优先保留。 以下图列出该封装的常用引脚常用功能，便于开发时查阅。

SWD 与原生功能冲突注意
  • PA13 / PA14 默认是 SWDIO / SWCLK，开发阶段不要轻易挪作普通 GPIO
  • PC13 / PC14 / PC15 驱动能力较弱，不适合直接带大电流负载
  • VDDIO2 供电域相关 IO 需要正确供电，否则对应引脚会被硬件关闭

4 快速上手​

你需要准备
  • USB Type-C 数据线 × 1（注意必须是数据线）
  • SWD 调试器 × 1（ST-Link V2 / DAP-Link / J-Link 任选其一）
  • 杜邦线 若干
  • 电脑（Windows / macOS / Linux）

4.1 安装开发环境​

  • STM32CubeIDE（推荐）
  • Keil MDK
  1. 前往 ST 官网下载 STM32CubeIDE。
  2. 安装完成后首次启动，选择一个 Workspace 文件夹。
  3. 菜单 File → New → STM32 Project，在芯片选择器中搜索 STM32F072CBU6。
  4. 填写项目名称，Targeted Language 选 C，选择对应固件包后完成创建。
  5. 如 ST-Link 未被系统识别，可补装 STSW-LINK009 驱动。
  1. 下载并安装 Keil MDK。
  2. 打开 Pack Installer，搜索 STM32F0，安装 Keil.STM32F0xx_DFP。
  3. 新建项目时 Device 可选择 STM32F072CBUx 或等效器件项。
  4. 安装 ST-Link 驱动后即可下载调试。

4.2 SWD 接线​

建议连接 4 根线（推荐 5 根）：

调试器 (ST-Link)          开发板 SWD 排针
─────────────            ──────────────
+5V  ────────────────── +5V  （可选，板子 Type-C 自带供电）
GND   ────────────────── GND
RST   ────────────────── NRST (Pin 7)
SWCLK ────────────────── SWCLK (PA14)
SWDIO ────────────────── SWDIO (PA13)

注意事项
  1. 调试时不建议同时接入 Type-C 供电 和 调试器供电，只能二选一连接。
  2. 建议连接 NRST，调试体验会更稳定。
  3. 开发早期不要把 PA13 / PA14 改成普通 GPIO，否则可能出现“连不上芯片”。
  4. 若程序错误导致 SWD 连接困难，可尝试 Connect Under Reset。

5 教学例程总览​

本开发板非常适合作为 F0 系列的“全功能入门板”，因为它同时具备 原生 USB、CAN、DAC、比较器和较多 GPIO。教学例程可以按四阶段逐步展开。

阶段主题核心能力
一基础外设驱动GPIO / TIM / ADC / UART
二通信协议实战I²C / SPI / USART / CAN
三USB 与混合外设USB CDC/HID / DAC / 比较器
四综合项目控制面板 / 键盘 / 小型仪器

STM32F072CBU6 使用注意事项
  • PA11 / PA12 是原生 USB 关键引脚，做 USB 工程时不要再挪作普通 GPIO
  • PA13 / PA14 是 SWD 调试口，量产前可重映射，开发期建议保留
  • PC13 / PC14 / PC15 驱动能力受限，不建议直接挂较大负载
  • VDDIO2 相关 IO 需确保供电正常，否则对应引脚不可用
  • 原生 USB、CAN、I²C、USART 可选引脚较多，建工程前建议先在 CubeMX 里确认最终复用组合

6 工程结构说明​

每个例程建议保持独立工程，目录结构如下：

ExNN_模块_功能/
├── Core/Inc/          ── 头文件
├── Core/Src/          ── 源文件
├── Drivers/           ── HAL 库驱动
├── README.md          ── 例程说明文档
└── .ioc               ── CubeMX 工程配置文件

所有用户代码建议写在 CubeMX 的 USER CODE BEGIN / END 区域内，方便后续重新生成外设配置而不丢失逻辑。

7 学习路径建议​

推荐进度

建议分 4 个阶段逐步完成：

  • 第一阶段：GPIO / TIM / ADC / UART
  • 第二阶段：I²C / SPI / 多串口 / CAN
  • 第三阶段：USB CDC / USB HID / DAC / 比较器
  • 第四阶段：做一个完整的小项目

如果你目标是做键盘、控制面板或桌面小设备，这块板的学习收益会比纯最小系统板更高。

8 常见问题​

烧录时提示 "No target connected" 或 "Error connecting to target"
  1. 检查 SWD 线是否接牢，尤其是 GND。
  2. 确认板子已正常供电，3.3 V 稳定。
  3. 尝试降低 SWD 频率。
  4. 如 PA13 / PA14 曾被错误配置为 GPIO，可尝试 Connect Under Reset。
  5. 检查 NRST 是否可用，必要时同时接上复位线。
串口没有输出 / 收到乱码
  1. 确认外接 USB-UART 模块已被系统识别，驱动安装正常。
  2. 确认代码和串口工具的波特率一致。
  3. 检查系统时钟是否正确配置到 48 MHz。
  4. 确认串口接线正确：PB6(USART1_TX) -> USB-UART_RX，PB7(USART1_RX) -> USB-UART_TX，并共地。
USB 工程枚举失败
  1. 检查是否正确使用了 PA11 / PA12。
  2. 确认 USB 相关时钟配置正确。
  3. 检查 USB 连接器、D+ / D− 走线和上拉配置。
  4. 确认没有把 PA11 / PA12 同时拿去做其他 GPIO 功能。
ADC 读数不准或一直为 0
  1. 建议先执行 ADC 校准。
  2. 确认引脚模式为模拟输入，没有开上拉/下拉。
  3. 检查 VDDA 供电是否正常。
  4. 用万用表确认输入电压真实存在。
